GRC 3060: Resources

Line graph

New document

  1. Go to https://public.tableau.com/app/discover

  2. Create → Web authoring

  3. Files → Upload from computer

  4. Go to Sheet 1.

Format the Fields

  1. Right-click Conversion → Change Data Type → Number (decimal).

  2. Right-click it again, choose Default Properties → Number Format → Percentage.

  3. Right-click Position 1 → Default Properties → Number Format → Currency.

  4. Right-click Position 2 → Default Properties → Number Format → Currency.

  5. Right-click Position 3 → Default Properties → Number Format → Currency.

Build the Line Chart

  1. Drag Conversion to the Columns shelf

  2. Crucial Step: Tableau will likely default this to a discrete dimension or try to SUM it. Right-click the green Conversion pill on the Columns shelf and select Dimension and change it to Continuous if it isn't already, so it forms a smooth continuous horizontal axis from 0.0% to 5.0%.

  3. Find the Measure Names field at the top bottom of your Data Pane fields list. Drag it onto the Filters shelf. Check the boxes only for Position 1, Position 2, and Position 3. Click OK.

  4. Drag the same Measure Names field from the top bottom of your Data Pane fields list and drop it directly onto the Color card inside the Marks shelf.

  5. In the Marks shelf drop-down menu, change the visualization type from Automatic to Line.
