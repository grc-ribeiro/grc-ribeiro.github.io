GRC 3060: Resources

Line graph

Create a new document

  1. Go to Tableau Public

  2. Go to Create → Web authoring

  3. When the Connect to Data panel shows up, go to the tab Files and choose Upload from computer

  4. Upload the Online campaign demo 1.csv file from your computer.

  5. Go to Sheet 1.

Click on Publish.

Format the Fields

  1. Right-click CTR → Default Properties → Number Format → Percentage.

  2. Right-click Profit position 1 → Default Properties → Number Format → Currency.

  3. Right-click Profit position 2 → Default Properties → Number Format → Currency.

  4. Right-click Profit position 3 → Default Properties → Number Format → Currency.

Click on Publish.

Build the line chart

  1. Drag CTR to the Columns shelf

  2. Right-click the green CTR pill on the Columns shelf and select Dimension and change it to Continuous if it isn't already, so it forms a smooth continuous horizontal axis from 0.0% to 5.0%.

  3. Drag Measure Values to the Columns shelf

  4. Find the Measure Names field at the top bottom of your Data Pane fields list. Drag it onto the Filters shelf. Check the boxes only for Profit position 1, Profit position 2, and Profit position 3. Click OK.

  5. Drag the same Measure Names field from the top of your Data Pane fields list and drop it directly onto the Color card inside the Marks shelf.

  6. In the Marks shelf drop-down menu, change the visualization type from Automatic to Line.

Click on Publish.
