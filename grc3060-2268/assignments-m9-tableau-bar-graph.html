Tableau: bar graph visualization

For this first lab, you will create a bar graph visualization, exactly like the one I showed in the lab. The instructions are listed below.

I suggest you don’t leave the lab before you finish it.

If you need any help, please let me know.

Create a new document

  1. Start by downloading the Online campaign data 2 file and save it to your Desktop.

  2. Double-click on the .zip file to extract the CSV file from it.

  3. Go to Tableau Public

  4. Go to Create → Web authoring

  5. When the Connect to Data panel shows up, go to the tab Files and choose Upload from computer

  6. Upload the Online campaign data 2.csv file from your computer.

  7. On the bottom left of your page, go to Sheet 1.

Click on Publish.

Format the Fields

  1. Right-click Conversion rate → Default Properties → Number Format → Percentage.

  2. Right-click Cost per click (CPC) 1 → Default Properties → Number Format → Currency (Standard).

  3. Right-click Cost per click (CPC) 2 → Default Properties → Number Format → Currency (Standard).

  4. Right-click Cost per click (CPC) 3 → Default Properties → Number Format → Currency (Standard).

  5. Right-click Profit before search cost → Default Properties → Number Format → Currency (Standard).

Click on Publish.

Create the parameters

CTR 1

  1. In your Data pane, click on the ▼ next to the Search field in the Data pane, and choose Create Parameter….

  2. Name the parameter CTR 1.

  3. Set Data type to Float, Display format to Percentage, and Current value to 0.015 (for 1.5%).

  4. For Allowable values, choose Range. Then choose Minimum 0, Maximum 0.05, and Step size 0.001.

  5. Click OK.

CTR 2

  1. Under Parameters, right-click on CTR 1 and choose Duplicate.

  2. Right-click on CTR 1 (copy) and choose Edit…

  3. Change the name to CTR 2.

  4. Change the Current value to 0.01 (for 1.0%).

  5. Click OK.

CTR 3

  1. Under Parameters, right-click on CTR 2 and choose Duplicate.

  2. Right-click on CTR 2 (copy) and choose Edit…

  3. Change the name to CTR 3.

  4. Change the Current value to 0.005 (for 0.5%).

  5. Click OK.

Click on Publish.

Create the calculated fields

Profit position 1

  1. In your Data pane, click on the ▼ next to the Search field, and choose Create Calculated Field….

  2. Name it Profit position 1.

  3. Make the calculation: [Profit before search cost] * ( [CTR 1] * [Conversion rate] * 1000 ) - ( [Cost per click (CPC) 1] * [CTR 1] * 1000 )

  4. Click OK.

  5. Right-click Profit position 1 → Default Properties → Number Format → Currency (Standard).

Click on Publish.

Profit position 2

  1. In your Data pane, click on the ▼ next to the Search field, and choose Create Calculated Field….

  2. Name it Profit position 2.

  3. Make the calculation: [Profit before search cost] * ( [CTR 2] * [Conversion rate] * 1000 ) - ( [Cost per click (CPC) 2] * [CTR 2] * 1000 )

  4. Click OK.

  5. Right-click Profit position 2 → Default Properties → Number Format → Currency (Standard).

Click on Publish.

Profit position 3

  1. In your Data pane, click on the ▼ next to the Search field, and choose Create Calculated Field….

  2. Name it Profit position 3.

  3. Make the calculation: [Profit before search cost] * ( [CTR 3] * [Conversion rate] * 1000 ) - ( [Cost per click (CPC) 3] * [CTR 3] * 1000 )

  4. Click OK.

  5. Right-click Profit position 3 → Default Properties → Number Format → Currency (Standard).

Click on Publish.

Build the bar graph

  1. Find the Measure Names field at the top of your Data Pane fields list. Drag it onto the Filters shelf. Check the boxes only for Profit position 1, Profit position 2, and Profit position 3. Click OK.

  2. Find the Measure Values field at the bottom of your Data Pane fields list. Drag it to the Columns shelf.

  3. Find the Measure Names field at the top of your Data Pane fields list. Drag it to the Rows shelf.

  4. Drag the same Measure Names field from the top of your Data Pane fields list and drop it directly onto the Color card inside the Marks shelf.

  5. Find the Measure Values field at the bottom of your Data Pane fields list. Drag it to the Label card inside the Marks shelf.

Click on Publish.

Include the controls

  1. In the Parameters section, right-click on CTR 1, and select Show Parameter.

  2. In the Parameters section, right-click on CTR 2, and select Show Parameter.

  3. In the Parameters section, right-click on CTR 3, and select Show Parameter.

  4. At this point, three sliders should show on the right.

Click on Publish.

Build the dashboard

  1. Click on the New Dashboard on the bottom‑left of the page.

  2. Once you’re in Dashboard 1, change its size to 1600px × 600px.

  3. Drag Sheet 1 from the sidebar to the empty canvas in the middle.

  4. Select the CTR 1 slider. Grab it by the top handle and drop it under the bar graph.

  5. Select the CTR 3 slider. Grab it by the top handle and drop it under the bar graph, to the right of the CTR 1 slider.

  6. Select the CTR 2 slider. Grab it by the top handle and drop it under the bar graph, to between the CTR 1 and the CTR 3 sliders.

Click on Publish one last time.

Visualize and share your dashboard

  1. Click on the × next to your name on the top‑right of the page.

  2. Play a little with the sliders just to have fun.

  3. Click the Share button.

  4. Click on the Copy Link button.

  5. Paste the link on a new tab of your browser.

  6. Copy the new URL from the address bar on the browser. (That’s the URL you need to submit on Canvas.)

Submission

Submit the second URL to Canvas.
