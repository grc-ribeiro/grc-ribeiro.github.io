Tableau: dashboard with two charts

For this first lab, you will create a dashboard with two charts, a vertical bar chart and a line chart, just like the one below:

The instructions this week are not exactly as detailed as last week.

I suggest you don’t leave the lab before you finish it.

If you need any help, please let me know.

Create a new document

  1. Start by downloading this zip file and extracting the CSV file from it.

  2. Create a new document in Tableau Public and upload the Rio daily precipitation.csv file.

First chart

  1. Create a new Calculated Field. You will use the formula DATEPARSE("format", value), where the format is the MM-dd (for month and day) and the valeu is the table Month Day. Name this calculated field Months.

  2. Make months the x‑axis and the average precipitation as the y‑axis.

  3. Make sure you have it as a bar chart and don’t forget to include the labels on the top of each bar. Set the labels in Tableau Bold, 10pt, blue.

  4. You may hide the Header on the left of the chart.

Second chart

  1. Add a New Data Source and upload the other LAX Rio airfare.csv file.

  2. Create a New Worksheet. On this new sheet, select the LAX Rio airfare database.

  3. Make months the x‑axis and the average price as the y‑axis.

  4. Make sure you have it as a line chart and don’t forget to include the labels for the prices.

  5. Change the line to red.

  6. Set the labels in Tableau Bold, 9pt, teal.

  7. You may hide the Header on the left of the chart.

Dashboard

  1. Create a New Dashboard and change its size to 1400px × 800px.

  2. Add Sheet 1 to the top and Sheet 2 to the bottom of the dashboard.

  3. Tableau will add the control for years on the top right. You may delete it.

  4. You may hide the Field Labels for Columns for both graphs too.

  5. Edit the title of the first graph as Monthly average precipitation in Rio de Janeiro (mm). Set the type to Tableau Book, 18pt.

  6. Edit the title of the second graph as Average airfare price for economy round trip from LAX to Rio in 2025 (USD). Set the type to Tableau Book, 18pt.

Visualize and share your dashboard

  1. Click on the × next to your name on the top‑right of the page.

  2. Click the Share button.

  3. Click on the Copy Link button.

  4. Paste the link on a new tab of your browser.

  5. Copy the new URL from the address bar on the browser. (That’s the URL you need to submit on Canvas.)

Submission

Submit the second URL to Canvas.
