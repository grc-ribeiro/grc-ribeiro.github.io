Report update Module 10

Tasks

On module 10, this is what is expected on your report:

  1. Visual language direction

    Develop one clear visual language direction for your application. Your direction should support the product’s intended personality, audience, and purpose.

    Define and apply a type family, type scale and hierarchy, color palette, color roles, imagery, icons, spacing, and overall tone.

  2. Design system

    In the User interface design chapter, create a section for your design system. Include the visual decisions that will be used consistently throughout your application. Show the actual colors, typefaces, text styles, spacing, buttons, form elements, icons, and other repeated components your interface uses.

  3. High-definition layouts

    Create at least ten high-definition screens for your application. These should be actual proposed interface designs, not wireframes. Apply your visual language and design system consistently across all screens. Include the content, color, typography, imagery, and interface details that would appear in the final product.

  4. Interactive elements and states

    Include interactive interface elements where appropriate, such as buttons, text fields, checkboxes, radio buttons, dropdowns, tabs, navigation, filters, toggles, or cards. Show relevant states, such as default, selected, hover, focus, disabled, error, success, or empty states. You do not need to show every state for every component, but your report should demonstrate that you considered how the interface behaves.

  5. Platform decisions

    If your application is designed for a phone, choose the platform: iPhone/iOS or Android. Your screens should follow that platform’s conventions for navigation, controls, spacing, and system elements. Do not design for a generic phone. Explain your platform choice briefly in the report.
