As promised, my paragraphs long rant:

The updated version of the Canvas assignments page is truly terrible.

The hierarchy and layout is scattered and confusing. The number of possible points is given more importance than the assignment title and is pushed toward the upper left corner, making it seem like it isn’t relevant to the other assignment information. The submission type and availability timing information, which were important parts of being able to scan an assignment’s requirements at a glance, cannot be found without scrolling to the submission at the bottom.

The first interactive feature that the user notices is attempt dropdown. But this dropdown is almost completely useless because students usually only submit an assignment once, so there would usually be zero or one attempt made on any given assignment. Therefore, a dropdown is a very poor choice to represent this information.

And the progress bar. When an assignment isn’t even started, it is shown to be in-progress and at an arbitrary 33% complete. It also shows “Next up: Submit Assignment,” as if that wasn’t completely obvious. When an assignment is submitted and we see the confetti, students correctly think that their process is complete. But the progress bar only goes to 67% because the next step is to “Review Feedback,” which isn’t applicable or necessary for the student to do for every assignment.

For submission, clicking the upload button offers no feedback because the file submission drag-in space has automatically been opened. Also, the Submit Assignment button is located at the bottom right corner. I literally did not even see it the first time I opened an assignment page with the new update—I thought the assignment was one of those non-submission assignments.

To sum up, the updated Canvas assignment page design has poor hierarchy, feedback, and visibility (and it’s also just plain ugly).
