GRC 4900: Resources

Class journal, module 12

It is easier to work with familiar icons than it is to create new ones. You don’t always need to design them with originality in mind.

“Don’t try to be original; just try to be good.”

Labels and icons go hand in hand. Labels help with ambiguity by describing an action or interaction, while icons help the user quickly find and repeat the action.

Precisely!

Our group decided to add a bright red color for one of our icons to symbolize an error with the technology. We figured it would stand out more if we didn’t use a color from our color palette.

That was probably a good decision.

Sometimes the best icon is just a label, but using a label in tandem with an icon allows for quicker performance.

And it’s fun. Fun is a huge aspect of usability too.

Figma components made it very easy to switch out our new icons from the placeholder ones.

True. Using the correct process often helps. (Figma components, Text styles in InDesign, HTML proper tags and classes, etc.)

If you upload an SVG file to Figma, you can edit the colors of the different components, add strokes, etc.

Keep your files as vectors if you can. Not only they are scalable, but much more easily editable.

They’re aren’t many times I am frustrated with InDesign but I was having some issues with frames inside textboxes from last week. Make sure your images are inside the textbox/ part of the string throughout the doc.

Using the story (cmd Y or ctrl Y) makes it easier to manipulate images inside a text frame.

To edit icons, we copy and pasted the svg into Illustrator, and then pasted that into Figma.

You could also edit it in Figma. But in this case, you should choose what’s most comfortable to you.

I learned that icons can sometimes have multiple meanings depending on their context. For example, a magnifying glass could represent searching or zooming in, so placement and visual context are important for avoiding confusion.

And it does make more sense for zoom than for searching, actually. But most of the time, it’s the visual context that makes us understand what it means.

I am curious to see how our group decides to film the video. We have our script ready, but I don’t have too much experience finding the right angles.

Pay attention to the lighting and framing of every frame. You can do it.

We already had icons in our high definition prototype, but we didn’t think too hard about it so it was nice replacing them and seeing it be much more cohesive.

And if you compare the old interface with this new one, you can probably see the difference.
